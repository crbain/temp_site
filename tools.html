In-house tools built for real offshore work.

Over the years I’ve developed a suite of focused tools to support AUV mission planning, offshore execution, navigation review, and delivery.

These tools were built in-house to solve real operational problems — streamlining workflows, reducing manual error, and improving clarity during offshore campaigns.

Mission planning AUV navigation QA & delivery Automation

How these tools are developed

The focus is practical: build small tools that remove friction from everyday operations and improve confidence in delivered results.

  • Built around offshore requirements and real workflows.
  • Designed to be maintainable and easy to use under time pressure.
  • Used to deepen capability across planning, analysis, and automation.

Selected tools

Mission Explorer

Desktop application for reviewing AUV missions by bringing planned lines, executed navigation, events, and logs into one interface.

Used for offshore QA, post-mission review, fast reporting, and export to DXF and Excel.

PyQt Track review Export

HUGIN Mission Planner (QGIS plugin)

Mission planning and line-generation plugin built directly inside QGIS for spatial accuracy and flexibility.

Supports survey line generation, turn handling, ordering patterns, launch point calculation, and mission export.

QGIS Line generation Mission export

Navigation & Event Review Utilities

Lightweight tools for parsing and visualising navigation, CP events, and logs to quickly answer operational questions.

Built to reduce reliance on vendor tooling and shorten turnaround time during offshore troubleshooting and QA.

Python Log parsing Operations support

Mission & Maintenance Tracker

Internal web application for logging missions, tracking component usage, recording faults, and maintaining service history.

Improves traceability across campaigns: hours, serials, maintenance status, and work completed.

Flask Asset tracking Traceability

Imagery & Media Workflow Tools

Utilities for handling large still-image datasets (batch processing, overlays, and organisation) to support fast review and delivery.

Built with performance in mind for high-volume offshore collections.

Batch processing QA support

3D Mission / Terrain Tools

Tools to combine mission lines with terrain models (DEM) for 3D-ready outputs and better altitude/terrain awareness during planning.

Useful for visual validation and risk reduction in complex bathymetry.

3D planning DEM sampling

In-house capability, not off-the-shelf dependency

All tools are designed and developed in-house as part of ongoing operational work, not as standalone software products.

Development is driven by offshore requirements — reducing manual handling, improving clarity during operations, and increasing confidence in delivered results.

Building these tools has been a deliberate way to strengthen technical capability across mission planning, navigation analysis, automation, and data quality — keeping solutions practical, maintainable, and aligned with how offshore work is actually executed.
